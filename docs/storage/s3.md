# S3-compatible storage

Use this backend for AWS S3, Wasabi, Backblaze B2, Cloudflare R2, a MinIO you already run, or anything else that speaks the S3 API.

## Settings

| Variable | Value |
|---|---|
| `HEARTH_STORAGE_BACKEND` | `s3` |
| `HEARTH_S3_ENDPOINT` | Host and port with no scheme, for example `s3.eu-central-1.amazonaws.com:443` |
| `HEARTH_S3_USE_SSL` | `true` for https to the endpoint |
| `HEARTH_S3_REGION` | What requests are signed for. Empty means `us-east-1`. Set it for AWS. |
| `HEARTH_S3_PATH_STYLE` | `true` to force `/bucket/key` addressing, which most self-hosted stores want |
| `HEARTH_S3_ACCESS_KEY`, `HEARTH_S3_SECRET_KEY` | The access key pair |
| `HEARTH_S3_PUBLIC_ENDPOINT` | Where a browser reaches the store. Required, and it must differ from the endpoint in production. |
| `HEARTH_STORAGE_BUCKET` | The bucket. Hearth creates it if the key may. |

Give the key read, write, and delete on that one bucket and nothing else.

## Helm

```yaml
s3:
  backend: s3
  endpoint: s3.eu-central-1.amazonaws.com:443
  region: eu-central-1
  useSSL: true
  bucket: my-hearth-files
```

Put `S3_ACCESS_KEY` and `S3_SECRET_KEY` in the Secret named by `existingSecret`. Set `garage.enabled: false` if you do not want the bundled Garage running beside it.
